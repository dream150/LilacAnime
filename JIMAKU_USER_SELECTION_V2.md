# Jimaku per-episode subtitle selection

- Jimaku is no longer automatically searched/downloaded in the background.
- Selecting the `Jimaku` subtitle source opens a picker for the current episode.
- The picker lists all matching ASS/SSA/SRT/VTT files returned by the Jimaku entry.
- The user selects the exact file to download/apply.
- Already-downloaded files are marked as saved and can be selected without another download.
- The selected file remains the primary `jimaku` subtitle for that episode through SubtitleStore.
- Re:Anime/Kairan/Csora subtitle behavior remains separate.
