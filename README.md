# 💜 About LilacAnime

**LilacAnime**는 사용자가 **언제 어디서든 애니메이션을 편하게 감상할 수 있도록** 만들어가는 Android 애니메이션 앱입니다.

애니메이션을 찾는 과정은 간단하게.

자막은 원하는 방식으로.

영상은 편안하게.

그리고 감상하는 동안에는 **앱이 방해하지 않도록.**

LilacAnime는 기능의 수보다 **사용자가 실제로 느끼는 편리함**을 중요하게 생각합니다.
